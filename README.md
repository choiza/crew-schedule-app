# 오늘 민주는

승무원 스케줄을 가족이 읽을 수 있게 바꿔 주는 웹앱입니다.
크루넷 월간 달력을 캡처해서 넣으면 코드 대신 "파리 12:05 출발", "휴무", "대기" 같은 말로 보여 주고,
공항 가는 날과 돌아오는 날에는 몇 시에 일어나 어느 버스를 타야 하는지 이유와 함께 추천합니다.

안드로이드와 아이폰 모두 브라우저로 열고 앱으로 설치할 수 있습니다.
가입이 필요 없고, 스케줄은 그 폰 브라우저에만 저장됩니다.

## 할 수 있는 것

**스케줄**
- 크루넷 달력 캡처를 올리면 폰 안에서 글자를 읽어 달력으로 만듭니다. 글로 붙여넣어도 됩니다.
- 한 번 다녀오는 비행(출국부터 귀국까지)을 한 묶음으로 보고 묶음마다 다른 색으로 칠합니다. 휴무는 늘 같은 초록색입니다.
- 날짜 칸에 도시, 공항 코드(`ICN→JFK`), 한국 시각(출발일은 출발, 도착일은 도착, 당일 왕복은 둘 다), 한국 공휴일을 보여 줍니다.
- 날짜를 누르고 "이 날 일정, 공항 고치기"를 누르면 그날 코드를 고치거나 지우거나 더하고, 편명마다 출발·도착 공항을 목록에서 고릅니다. 공항을 바꾸면 같은 편명이 들어간 모든 날짜에 바로 반영됩니다.
- 근무 코드(ATDO, GRD 등)의 뜻과 종류(휴무, 대기, 교육, 근무)는 설정 맨 아래 "코드 뜻"에서 확인합니다. 맞으면 "맞음"을 눌러 확정하고, 확정한 코드는 목록에서 내려갑니다. 새 스케줄에 처음 보는 코드가 나오면 다시 뜨고, 없는 코드는 직접 추가할 수 있습니다.
- 편명의 출발·도착 시각을 고칠 수 있습니다.
- 달력 오른쪽 위에 그 달 총 비행 시간을 보여 줍니다. 비행시간은 블록 타임(이륙하려고 처음 움직인 때부터 착륙해 멈춘 때까지, 항공안전법 시행규칙 별표 18) 기준이고, 대한항공 계획 시간표 값을 쓰며 표에 없는 편은 거리로 추정합니다. 누르면 편별 시간, 올해 누적과 객실승무원 연간 한도(1,200시간) 대비 비율이 나오고, 편별 시간을 고칠 수 있습니다.

**가족과 나누기**
- 맨 위 카드에 오늘 어디 있는지, 해외면 현지 시각과 한국과의 시차를 보여 줍니다.
- "달력 공유하기"는 버스와 기상 시각을 뺀 달력 한 장을 이미지로 만들어 카톡 등으로 보냅니다.
- 달마다 휴무와 근무만 적힌 근무표를 A4 가로 이미지(3508×2480, 300dpi, 인쇄용), 글, 엑셀(CSV)로 뽑습니다.
- 한 폰에서 여러 사람의 스케줄을 따로 볼 수 있습니다. 제목을 누르면 사람을 바꾸거나 추가합니다. 설정도 사람마다 따로 저장됩니다.
- 스케줄을 파일로 보내고 다른 폰에서 받아 넣을 수 있습니다.

**공항버스**
- 출발지를 우선순위로 정합니다(처음 값: 미금, 수지, 분당 서현). 위 순위부터 맞는 차를 찾고, 없으면 다음 순위에서 고릅니다.
- 지역을 추가하면 고른 정류장에 서는 공항버스를 자동으로 가져옵니다. 내 위치에서 가까운 정류장 순으로 볼 수 있습니다.
- 인천에서 뜨는 비행은 인천공항 제2터미널, 김포에서 뜨는 비행은 김포공항으로 계산합니다.
- 공항 가는 날: 공항 도착 목표(인천 3시간 전, 김포 2시간 전)에 맞는 차 가운데 집에서 가장 늦게 나서도 되는 차를 고릅니다.
  1순위 출발지에서 맞는 차가 목표보다 "다음 출발지로 넘기는 기준"(처음 값 90분)보다 더 일찍 닿으면 2순위 출발지 차도 봅니다.
  고른 차의 기상 시각, 집에서 나갈 시각, 공항 도착 예상 시각을 보여 줍니다.
- 돌아오는 날: 착륙 후 나오는 시간을 더해 집에 가장 빨리 닿는 차를 고릅니다.
- 추천마다 "이 차를 추천한 이유"와 걸리는 시간의 근거(시간표, TMAP 예측, 추정, 설정값)를 적고, 다른 후보도 보여 줍니다.
- 후보에서 "이 차로 예매함"을 누르면 그 차 기준으로 일정을 다시 잽니다. 예매한 뒤에도 다른 차로 바꿀 수 있고,
  비행 시각이 바뀌어 예매한 차가 안 맞게 되면 경고하고 달력 위 목록에 다시 올립니다.
- 비행 며칠 전에 예매 알림을 줄지 정할 수 있습니다. 달력 위 목록과 캘린더 파일에 들어갑니다.
- 안드로이드는 알람 앱을 시각이 채워진 채로 열고, 아이폰은 캘린더 알림으로 넣습니다.
- 날짜 화면의 "시간 고치기"에서 준비 시간, 정류장까지 시간, 버스 타는 시간 등을 바로 고칠 수 있습니다.

**비행 당일 실제 시각 (켜야 함)**
- 인천공항·김포공항 공공데이터에서 오늘 비행의 예정·변경 시각, 게이트, 상태를 30분마다 가져옵니다.
- 바뀐 시각은 달력, 버스 추천, 예매한 차 경고에 바로 반영됩니다.

### 걸리는 시간 계산 순서

1. **설정값**: 설정에 직접 넣은 분이 있으면 그 값을 씁니다.
2. **시간표**: 공항 도착 시각이 적힌 노선(5100, 5200)은 그 차이를 씁니다.
3. **TMAP 예측**: 예측표가 있으면 요일과 시간대의 자동차 소요 시간에 버스 보정을 곱합니다.
4. **추정**: 정류장별 평소 시간에 출퇴근, 금요일 오후, 주말 낮, 일요일 귀경길 보정을 곱합니다.

## 실행

빌드가 필요 없습니다. 아무 정적 서버로 폴더를 열면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/family.html` 을 엽니다.
`family.html` 을 파일로 직접 열면 캡처 인식이 동작하지 않으니 꼭 서버로 열어 주세요.

## 폰에서 쓰기 (GitHub Pages)

1. 이 저장소의 **Settings → Pages** 에서 Source를 `main` 브랜치의 `/ (root)` 로 둡니다.
2. 잠시 뒤 `https://choiza.github.io/crew-schedule-app/` 가 열립니다. 첫 화면은 `family.html` 로 넘어갑니다.
3. 폰에서 그 주소를 열면 설치 안내가 나옵니다.
   - 아이폰: 사파리 공유 버튼 → 홈 화면에 추가
   - 안드로이드: 크롬 메뉴 → 앱 설치 (또는 앱 안의 "앱으로 설치" 버튼)
4. `install.html` 은 안드로이드 앱 파일 받기와 아이폰 홈 화면 추가를 한 장에 모은 설치 안내 페이지입니다.

## 안드로이드 앱 (APK)

웹 앱을 [Capacitor](https://capacitorjs.com/)로 감싼 안드로이드 앱입니다. `android/` 폴더가 앱 프로젝트이고, 앱 안에서는 근무표 이미지나 캘린더 파일을 저장할 때 안드로이드 공유 창(카톡, 드라이브, 파일)이 열립니다.

**GitHub이 자동으로 만들기 (PC에 아무것도 설치하지 않아도 됨)**

1. 서명 키를 저장소 **Settings → Secrets and variables → Actions** 에 4개 넣습니다.
   - `ANDROID_KEYSTORE_BASE64`: `release.keystore` 를 base64로 바꾼 글
   - `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`, `ANDROID_KEY_ALIAS`
   - 서명 키는 저장소에 올리지 말고 따로 보관합니다. 키를 잃어버리면 이미 설치한 폰에 새 버전을 덮어 설치할 수 없습니다.
2. `main` 에 올리면 **Actions → Android 앱 만들기** 가 돌고, 끝나면 **Releases → latest** 에 `oneul-minju.apk` 가 올라갑니다.
3. 폰에서 `https://github.com/choiza/crew-schedule-app/releases/latest/download/oneul-minju.apk` 를 열어 받습니다.
   처음 설치할 때 "출처를 알 수 없는 앱 허용"을 한 번 켭니다.

**직접 만들기 (JDK 21, Android SDK 필요)**

```bash
npm install
npm run android
cd android && ./gradlew assembleRelease
```

서명하려면 `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` 환경 변수를 넣고 만듭니다.

## 아이폰

아이폰은 앱스토어나 TestFlight를 거치지 않은 앱 파일을 설치할 수 없습니다. 방법은 셋입니다.

| 방법 | 필요한 것 | 비고 |
|---|---|---|
| 홈 화면에 추가 (지금 방식) | 없음 | 사파리 공유 → 홈 화면에 추가. https 주소여야 오프라인 보기, 내 위치가 동작 |
| 케이블로 직접 설치 | Mac, Xcode, Apple ID | 무료 계정은 7일마다 다시 설치해야 함 |
| TestFlight, 앱스토어 | Apple Developer Program (연 99달러) | 가족에게 링크로 배포, 90일마다 새 빌드 |

Capacitor iOS 프로젝트는 `npx cap add ios` 로 만들 수 있습니다(Mac, Xcode 필요).

## 비행 당일 실제 시각 켜기

공공데이터포털(data.go.kr)에서 아래 두 API를 활용 신청합니다. 개발 계정은 자동 승인됩니다.

- 인천국제공항공사 여객편 운항현황(다국어): https://www.data.go.kr/data/15095093/openapi.do
- 한국공항공사 실시간 항공기 운항정보 조회: https://www.data.go.kr/data/15158625/openapi.do

**권장: 키를 숨기는 중계 주소 쓰기**
1. Cloudflare Workers에 `scripts/flight-status-worker.js` 내용을 붙여 넣어 배포합니다.
2. Worker 설정에서 비밀값 `SERVICE_KEY`(포털의 "인코딩" 인증키)와 변수 `ALLOW_ORIGIN`(예: `https://choiza.github.io`)을 넣습니다.
3. `src/family/config.js` 를 이렇게 바꿉니다.
   ```js
   FLIGHT_STATUS: { enabled: true, proxyUrl: 'https://<이름>.workers.dev/', serviceKey: '', refreshMinutes: 30 }
   ```

**간단하지만 키가 보이는 방법**: `serviceKey` 에 인코딩 인증키를 바로 넣어도 됩니다. 공개 저장소에 올리면 누구나 키를 볼 수 있습니다.

응답 필드 이름은 공공데이터포털 문서를 기준으로 했습니다. 처음 켠 날 비행이 있으면 날짜 화면의 "실시간" 줄이 나오는지 확인해 주세요.
대한항공은 공개 운항 API가 없어 한국 공항 쪽 시각만 가져옵니다.

## TMAP 예측 켜기

요일과 시간대별로 더 정확한 소요 시간을 쓰려면 TMAP 타임머신 길 안내 예측표를 만듭니다.

1. [SK 오픈API](https://openapi.sk.com)에 가입하고 앱을 만들어 TMAP 앱 키를 받습니다.
2. 먼저 요청 모양만 확인합니다.
   ```bash
   node scripts/tmap-travel-times.js --dry-run --pairs miguem>ICN --hours 9
   ```
3. 한 구간, 한 시간대로 실제 응답을 확인합니다.
   ```bash
   TMAP_APP_KEY=발급받은키 node scripts/tmap-travel-times.js --pairs miguem>ICN --hours 9
   ```
4. 문제가 없으면 범위를 넓힙니다. 이미 받은 값은 건너뜁니다.
   ```bash
   TMAP_APP_KEY=발급받은키 node scripts/tmap-travel-times.js --hours 4-22
   ```
5. 결과는 `src/family/travel-data.js` 에 저장되고 앱이 자동으로 씁니다.
   끄려면 `src/family/config.js` 의 `TRAVEL.useTmap` 을 `false` 로 바꿉니다.

API 형식은 SK 오픈API 문서의 "타임머신 자동차 길 안내"를 기준으로 적었습니다. 처음에는 3번처럼 작게 돌려 응답을 확인해 주세요.
앱 키는 저장소에 올리지 마세요. 스크립트는 환경변수로만 키를 받습니다.

## 광고 켜기

맨 아래 광고 자리는 준비되어 있고 기본으로 꺼져 있습니다. `src/family/config.js` 에서 켭니다.

```js
ADS: {
  enabled: true,               // 켜기
  provider: 'adsense',         // 'adsense' 또는 'adfit'
  adsense: { client: 'ca-pub-게시자ID', slot: '광고단위번호' },
  adfit: { unit: 'DAN-광고단위ID', width: 320, height: 100 }
}
```

광고는 광고사 심사를 통과한 주소에서만 실제로 나옵니다.

## 여러 사람, 여러 폰

- 한 폰 안에서는 사람을 여러 명 두고 바꿔 가며 볼 수 있습니다.
- 폰끼리 자동으로 맞춰지지는 않습니다. 계정으로 자동 공유하려면 로그인과 저장 서버(예: Firebase, Supabase)가 필요합니다.
- 지금은 "스케줄 파일로 보내기"로 만든 파일을 카톡 등으로 보내고, 받은 폰에서 "파일에서 받기"로 넣습니다.

## 개인정보

- 스케줄, 설정, 고친 내용은 모두 그 기기 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.
- 캡처 인식은 브라우저 안에서 합니다(Tesseract). 사진이 밖으로 나가지 않습니다.
- 밖으로 나가는 요청: 글꼴(Google Fonts), 켰을 때의 광고 스크립트와 운항 정보 요청(편명만 보냄),
  위치를 눌렀을 때의 브라우저 위치 확인(기기 안에서만 씀), 버튼을 눌렀을 때 여는 버스타고·티머니GO·앱스토어 링크.
- 브라우저의 사이트 데이터를 지우면 스케줄도 지워집니다. 가끔 파일로 보내 두면 안전합니다.

## 한계

- 실제 폰에서 안드로이드 알람 앱 열기와 버스타고 앱 열기는 기기마다 다를 수 있습니다.
- 버스타고는 날짜와 노선을 미리 채워 여는 링크를 공개하지 않아, 앱을 여는 데까지만 합니다.
- 앱을 열지 않아도 오는 푸시 알림은 서버가 필요해 넣지 않았습니다. 캘린더 알림으로 대신합니다.
- 실시간 운항 정보는 앱이 열려 있을 때 갱신됩니다.
- 편명 시각은 기본 시간표 기준입니다. 날짜마다 다르면 날짜를 눌러 고쳐 주세요.
